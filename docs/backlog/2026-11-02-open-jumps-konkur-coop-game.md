## 2026-11-02 20:36–20:50 — этап 6, реализация `shared/` (цикл «правила и судейство»)

Реализованы девять модулей по одобренным тестам, заглушки удалены (`shared/src/errors.ts` убран, `NotImplementedError` больше не нужен). Решения внутри реализации (в пределах §2.7 плана):
- `faults`: норма времени округляется вверх до секунды с защитой от шума плавающей точки (ε = 1e-9); штрафы за время — потолок разницы; предел = min(2·норма, 150).
- `heightClasses`: таблицы масштаба окна по классам 50…100 см = 1.1, 1.0, 0.9, 0.8, 0.7, 0.6; вероятность повала на карьере = 0.45, 0.50, 0.56, 0.62, 0.68, 0.74.
- `rng`: mulberry32; строковые семена через FNV-1a; `chance` строит генератор из «семя|барьер|попытка».
- `takeoff`: модификаторы окна вынесены в `WINDOW_MODIFIERS` (резкий поворот 0.7, спуг 0.7, острый угол 0.8, карьер 0.5, бонус лидера ×1.25 только для clean-тира); исходы — фабрики с испанскими метками (perfecta, cero_faltas, batida_corta, batida_larga, rehuse, desvio, caida); порядок веток судьи: нет тапа/дальше ±400 → (карьер: закидка+падение | плохой заход: закидка | иначе: close) → perfect-тир → clean-тир (карьер: шанс повала по высоте) → промах (острый угол: обнос | карьер: падение | рано: long / поздно: chip).
- `packetTiming`: порядок проверок пакета — после дедлайна → слишком старый → из будущего; `AttemptJudge` хранит последний тик и бросает `Error('packet out of order…')` при нарушении контракта очереди; `decision` отдаёт копию состояния.
- `attempts`: неповиновения нумеруются раундом через `refusalFaults`; падение — не неповиновение; после последнего барьера `currentFence = fenceCount + 1`; записи времени помечены `kind: 'time'`, метка `tiempo`.
- `heats`: перемешивание Фишера–Йетса по семени `heats|<seed>`, затем стабильная сортировка по классу для «lowest-class-first».
- `assists`: авто-тап schoolmaster — магнитуда от perfectMs + 1 до cleanMs эталонного окна, знак по второму броску; «расширенное окно» только в тренировке; `freezeForRound` — замороженная копия.
- `pranks`: порядок проверок — выбывший атакующий, заряды, отказ (не для толчка), иммунитет, активный эффект, полёт, зона барьера с учётом длительности эффекта в темпах, пауза после посадки; отмена эффектов по отказу касается только фырка и морковки.
